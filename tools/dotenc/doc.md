# dot配置文件加密工具 dot encrypt config file

本工具可以基于*dot配置文件明文*，生成*私钥*和*配置文件密文*

## 使用

在当前目录下：`go install`

检查是否安装成功：`dotenc -h`

- go module path: 本工具计划上传到dot，考虑到我没有dot上传权限以及dot库本身达到450MB fork起来也麻烦，所以计划由jayce提交

使用：`dotenc`（假设当前路径为`/cmd/demo/`）

- 如果你的主要文件名与路径名不同，请通过`-n`参数指定生成文件名称
  - 名称不匹配：例如你的可执行文件名为`main`、配置文件名为`main_local.toml`，此时文件名与路径名(`demo`)不匹配
- 如果你的配置文件明文不是`demo_local.toml`，请通过`-c`参数指定明文的配置文件名称

## 设计

设计意图：基于配置文件明文，可以更方便的生成配置文件密文和私钥

设计预期：

1. 可以使用`go install`安装本工具
2. 切换到一个路径下使用
3. 关键参数提供默认值，也支持通过命令行参数设置
   - 关键参数：包括生成文件主要名称（例如`demo.pri`中的`demo`）、明文配置文件名等

## 技术准备

1. 经测试，使用多个key指向同一个命令行参数时实际生效情况：
   - 不提供key：默认值
   - 提供一个key：提供的值
   - 提供多个key：最后一个key的值
